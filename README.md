## 🚀 How to Run

No build step or installation required!

1. Open `index.html` directly in any web browser (Chrome, Edge, Firefox, Safari).
2. Alternatively, if using VS Code, use the **Live Server** extension to preview.

---

## 📸 Adding Your Own Photo

Simply place your photo named `profile.jpg` into this folder:
```
Pavin portfolio/
├── index.html
├── style.css
├── script.js
├── avatar.svg
└── profile.jpg   <-- Place your photo here!
```
The website will automatically detect and display it inside the glowing neon frame.
